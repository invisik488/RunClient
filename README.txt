ToshibaDLC - Локальный сайт с настоящей базой данных
=====================================================

ЗАПУСК
------
Запусти start.bat (двойным кликом).
Сайт откроется на http://localhost:8080

Нужен Python 3 (sqlite3 уже встроен, ничего доустанавливать не надо).
Если Python не найден - поставь: https://www.python.org/downloads/
(при установке обязательно поставь галочку "Add Python to PATH")


БАЗА ДАННЫХ
-----------
Всё хранится в настоящем файле БД SQLite: toshibadlc.db
- пароли хешируются (PBKDF2-SHA256), в базе НЕ хранятся в открытом виде
- сессии - через HttpOnly cookie (токены в таблице sessions)
- таблицы: users, sessions, settings
БД создаётся автоматически при первом запуске (с админом).
Чтобы начать заново - просто удали файл toshibadlc.db.


АДМИНКА
-------
Логин:  admin
Пароль: admin123

Панель: http://localhost:8080/admin/
(ссылка "Admin" появляется в меню после входа под админом)

Возможности:
- статистика (всего / с подпиской / забанено / админов)
- пользователи: бан/разбан, удаление, +30 дней подписки, сброс HWID, назначение админов, поиск
- настройки сайта (название, версия, Discord, Telegram) - сохраняются в БД
Доступ к админ-API защищён: обычный пользователь получает 403.


ЛОКАЛИЗАЦИЯ
-----------
Переключатель языка (RU / EN) в правом верхнем углу меню на всех страницах.


АРХИТЕКТУРА
-----------
- server.py       - бэкенд (Python, только стандартная библиотека): раздаёт сайт + /api/*
- toshibadlc.db   - база данных SQLite
- assets/local.js - фронтенд-логика (запросы к API, тосты, язык, тема)
- admin/          - админ-панель

API (POST, JSON, авторизация по cookie):
  /api/login  /api/register  /api/logout  /api/profile
  /api/activate-key  /api/promo/check  /api/change-password  /api/change-email
  /api/admin/stats  /api/admin/users  /api/admin/user/update  /api/admin/settings
  GET /api/settings

Тестовые промокоды: TOSHIBA (15%), DLC (10%), ADMIN (50%)
Ключи в профиле: любой = 30 дней, со словом 90 = 90 дней, FREE = 7 дней, LIFE = навсегда.
